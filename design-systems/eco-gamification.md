# Theme: Eco Gamification

## Direction

Friendly, modern eco-gamification. Feel ecological, optimistic,
approachable, energetic and trustworthy. Do not feel corporate,
childish, excessively colorful or generic SaaS.

## Colors

Primary: #0E5A54 Primary Dark: #062623 Primary Light: #E7EFEE
Background: #FFFFFF Surface: #FFFFFF Text: #1E1E1E Text Secondary:
#757575 Text Muted: #9CA3AF Border: #E1E4EA Success: #34C759 Warning:
#FF8D28 Error: #FF383C Info: #6155F5 Success Soft: #D4F4D9 Warning Soft:
#FFE8D4 Error Soft: #FFD7D8 Info Soft: #E7E5FF

Optional application background: linear-gradient(194deg,
rgba(255,255,255,1) 0%, rgba(231,239,238,1) 100%)

Keep gradients subtle.

## Typography

Font: Figtree

400 Regular, 500 Medium, 600 SemiBold, 700 Bold.

H1 24/32, H2 20/28, H3 16/24, Body 16/24, Secondary 14/20, Small 12/16.
Bottom navigation labels may use 10/14.

## Spacing

8px grid: 4, 8, 16, 24, 32, 40, 48.

## Radius
Default 12px. Cards 16px. Featured 20px. Buttons 12px. Pills 9999px.


## Borders and shadows

Default border: 1px solid #E1E4EA.

General shadow: 0 2px 4px rgba(70,70,70,0.1) Button shadow: 0 2px 4px
rgba(10,64,60,0.1) Bottom navigation: 0 1px 5.8px rgba(0,0,0,0.25)

Prefer borders over shadows. Do not shadow every card.

## Components

Cards are white, bordered and friendly. Gamification cards may use
subtle gradients, accent backgrounds, large numbers, progress and
badges.

Primary buttons use green + white. Secondary buttons use light
green/neutral + dark green.

Status badges use the soft semantic colors.

Important metrics such as points, levels and streaks should have strong
hierarchy.

## Navigation

Mobile bottom nav: white, subtle top shadow, active green, inactive
gray, 10px labels.

## Nuxt UI mapping

primary → #0E5A54 success → #34C759 warning → #FF8D28 error → #FF383C
info → #6155F5 neutral → neutral gray scale

## Avoid

Childish cartoon styling, rainbow palettes, excessive emoji, generic
AI-SaaS purple, excessive glassmorphism and giant rounded rectangles.
