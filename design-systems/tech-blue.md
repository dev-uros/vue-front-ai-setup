# Theme: Tech Blue

## Direction

Modern technical dashboard for data-heavy products. Technical, fast,
clear, modern, trustworthy and data-oriented.

## Colors

Primary: #2563EB Primary Dark: #1D4ED8 Primary Light: #DBEAFE
Background: #F8FAFC Surface: #FFFFFF Text: #0F172A Text Secondary:
#64748B Text Muted: #94A3B8 Border: #E2E8F0 Success: #16A34A Warning:
#F59E0B Error: #DC2626 Info: #0EA5E9

## Typography

Font: IBM Plex Sans. Weights 400, 500, 600, 700.

H1 28/36, H2 22/30, H3 18/26, Body 14/20, Small 12/16.

Use tabular or monospaced numerals where appropriate for IDs,
timestamps, metrics and technical values.

## Spacing and radius

Spacing: 4, 8, 12, 16, 24, 32, 40, 48px.

Default radius 8px. Cards 10px. Inputs/buttons 8px. Pills 9999px.

## Components

Cards: white, 1px border, 8-12px radius, minimal shadow.

Metric cards prioritize the number.

Tables use approximately 44px rows, subtle separators, compact headers,
right-aligned numeric columns, badges and restrained hover states.

Filters should be compact toolbars using UInput, USelect, USelectMenu
and UPopover.

Navigation should favor sidebar/top navigation and compact groups.

## Nuxt UI mapping

primary → #2563EB neutral → slate success → green warning → amber error
→ red info → sky blue

Prefer UTable, UButton, UInput, USelect, USelectMenu, UCard, UBadge,
UAlert, UPopover, UModal, UDropdownMenu, UTabs and UProgress.

## Visual goal

Modern technical SaaS dashboard. Make large amounts of information easy
to scan.
